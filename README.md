# Market Council

The app and the calculation code of a personal share-monitoring tool.

- This repository is public and holds no personal data: no holdings, balances, decisions or answers.
- The records live in a private repository. The app reads them in the browser with a token that is
  saved only on the owner's device; the jobs here fetch them with a repository secret and write the
  results back. Job logs here say only which script ran and whether it worked.
- The tool shows information and sends reminders. It never places orders.
- Nothing here is financial advice. Every figure is an estimate with its method shown in the app.
